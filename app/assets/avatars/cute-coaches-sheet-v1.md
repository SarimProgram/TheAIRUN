# Cute versions of the existing home avatars

Runtime asset: `cute-coaches-sheet-v1.png`, 512 x 256 transparent indexed PNG, 38,239 bytes. Four 128px frames per row: neutral, head tilt, blink, wave. Male coach is row 1, female coach is row 2.

Created with the built-in image generation tool using `assets/imagechat-male.png` and `assets/imagechat-female.png` as identity references. Preserves the existing human characters, hairstyles, athletic outfits, colors and watches. The 1,653,991-byte source was downscaled using Lanczos and quantized to 192 colors. Shared local texture; no network fetch. Animation pauses offscreen, in the background, and with Reduce Motion.

Playback uses continuous UI-thread bob, sway and breathing transforms over a 2.4-second loop. Atlas changes provide brief expressions (90ms blink, 420ms greeting), rather than holding each sprite for 300ms. The atlas is unchanged; movement does not add image weight or use a JavaScript frame timer.
