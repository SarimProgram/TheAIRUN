# Weight journey character sheets

Created with the built-in image generation tool. Each transparent PNG contains ten full-body figures in a five-column, two-row grid, ordered left to right across the top row, then the bottom row. Male clothing is teal; female clothing is coral. Both use the existing faceless 3D character family.

- `weight-journey-men-v1.png`: selected male sheet, after removing background haze.
- `weight-journey-women-v1.png`: selected female sheet.

`WeightJourneyCharacter` clips the sheets at runtime without twenty duplicate images. They are bundled local assets; no remote image downloads are required. The header selects a stage using logged weight (stage zero before a weigh-in); character-bearing weekly cards select a stage using their projected weight. The timeline opens with one character, then alternates two original icons and two characters; the final week keeps the trophy. These are decorative stages relative to the plan, not measurements of body shape or a guarantee of appearance.

## Male generation prompt

+Use case: stylized-concept. Create ONE production sprite sheet for a mobile fitness app, landscape canvas, exactly TEN full-body adult MALE character sprites in a perfectly regular FIVE COLUMNS by TWO ROWS grid. Use the attached male character only as the identity/style/outfit reference. Every cell exactly the same dimensions; generous transparent margins; character centered at x=10%,30%,50%,70%,90% canvas width, and row centers y=25%,75%. All ten heads same height within their row, all ten soles same baseline within their row. Each complete figure head to shoes fits inside its own cell without touching any cell boundary. No text, labels, numbers, grid lines, props, background, floor, or shadow outside silhouettes. GENUINELY TRANSPARENT alpha background.
Subject: the same faceless tan-skinned adult man with swept brown hair, blank face and two white stylized eyes, teal/turquoise athletic fitted T-shirt and teal shorts, matching teal-and-white trainers. Same friendly upright confident stance in every cell: front view, feet comfortably spaced, arms relaxed slightly away from torso, hands open at sides. Same face, hairstyle, age, height, camera, clothing, lighting, stance across all sprites.
Sequence strictly left-to-right top row then left-to-right bottom row: ten smoothly graded body-composition stages. Cell 1 has a very large rounded body with substantial soft belly, broad waist, large arms and thighs, visibly heavier but realistically proportioned; cell 2 slightly smaller; cell 3 smaller; cell 4 smaller; cell 5 moderately heavy; cell 6 average build; cell 7 moderately lean; cell 8 fit; cell 9 athletic; cell 10 lean athletic with subtly defined muscles, never an exaggerated bodybuilder. Make all TEN stages distinctly different with smooth plausible steps. Same respectful positive body language in all. Clothing remains fully covering torso and upper thighs in every stage, sized properly for each body. No squeezed inflated balloon anatomy.
Style: polished high-end soft 3D mobile game character, matching reference material/lighting and faceless design. Clean silhouettes readable at tiny phone-card size. Highest detail and crisp edges. Landscape 5:2 width-to-height grid suitable for cropping ten equal portrait cells.
